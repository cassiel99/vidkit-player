Автоподключение Vidkit Player

1. Обычный <video controls> → станет плеером

2. Видео из HLS (<source>) → плеер с выбором качества до 4K

3. Фоновое видео без controls → остаётся как есть

4. data-vidkit="off" → исключено автором

5. С рекламой через data-ads

6. Видео, добавленное скриптом позже → тоже подхватывается
